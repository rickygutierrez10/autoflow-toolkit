# Changelog

All notable changes to AutoFlow Toolkit will be documented in this file.

This project follows a version-based release history.

## [0.1.0] - 2026-11-23

First public release of AutoFlow Toolkit.

### Features
- Organise files into folders based on file extensions.
- Preview file organisation before making changes.
- Support recursive file organisation.
- Detect duplicate files using SHA-256 hashing.
- Calculate potential storage savings from duplicate files.
- Export duplicate detection results to CSV reports.
- Generate activity logs.

### Quality and testing
- Automated unit tests.
- Code quality checks using Ruff.
- GitHub Actions continuous integration.
- Python package build and installation testing.

### Documentation
- Project README and usage instructions.
- Contribution guidelines.
- Bug report and feature request templates.
- Pull request template.
